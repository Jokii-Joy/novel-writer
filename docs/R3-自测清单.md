# R3 自测清单（16 项逐条对应）

> 这份清单把第三轮提的每一条对上「改了什么 / 在哪儿看 / 怎么算过」。
> 全部为人工目检步骤，不依赖任何测试脚本。

## 准备

1. 侧栏点书本图标进入「小说创作台」。
2. 若界面是旧样子：`plugin_manager action=set_plugin target=include:novel-writer enabled=false` 再 `enabled=true`，然后刷新页面（构建产物有缓存）。

---

## ① 阿里云盘不会用 → 简化入口

- **改了什么**：云端备份对话框改成「本地备份 / 云端备份」两个 tab；云端首选**简单模式（WebDAV 三字段 + 保存并连接）**；阿里云盘独立一个大按钮「使用阿里云盘（扫码登录）」；`Client ID / Secret` 收进默认折叠的「▸ 高级 · 自备应用」。
- **在哪儿看**：`⚙ 设置` →「导出与文件」→「本地 / 云端备份…」→ 切「云端备份」。
- **算过**：不用翻文档就能看懂两条路（扫码 / 填地址）；点扫码若没填应用凭证，会**就地展开高级区并提示**「需要先填 Client ID / Secret」，不再一点就 405。
- 参见 `docs/screenshots/final-08-backup.png`。

## ② 操作没动画 → 全局动效

- **改了什么**：新增 `96-motion.js`（动效 token）与 `97-theme.js`（精修层）：`--nw-dur .18s`、`--nw-ease cubic-bezier(.2,.7,.2,1)`、`--nw-ease-pop`；对话框 `nw-fade-in` / `nw-fade-up`，toast `nw-toast-in`，浮动坞 `nw-pop`，按钮 hover 位移 / 按下缩放。
- **在哪儿看**：开任何对话框、切主题、展开浮动坞、hover 工具栏与目录行。
- **算过**：有过渡即算过；系统开了「减少动态效果」时会自动降级为无动画（这是预期）。

## ③ 不要执行测试（硬约束）

- 已遵守：R3 只做了语法校验、挂载冒烟、点击冒烟、接口冒烟与截图目检，**没有跑任何 verify-* 或 GUI 测试套件**。详见 README「3. 验收状态」。

## ④ 沉浸模式去掉顶栏、Esc 退出

- **改了什么**：进入沉浸后 `.nw-root[data-immersive="1"]`，工具栏 / 目录 / 分隔条 / 状态栏 / 浮动坞**全部卸载**，只剩满屏写作面；页宽放宽到 `max(页宽, 880px)`；自动开打字机；`Esc` 退出并恢复一切。
- **在哪儿看**：工具栏 `⛶`，或 `⚙ 设置` →「外观」→「沉浸模式」。
- **算过**：进入后**看不到任何横栏**（连顶部都没了）；按 Esc 回到原样，正文不受影响。
- 参见 `docs/screenshots/final-06-immersive.png`。

## ⑤ 创作台侧栏（目录）支持隐藏

- **改了什么**：工具栏最左 `☰` 一键收起/展开目录，状态存 `localStorage['nw.shelfOpen']`；目录顶栏也有 32×32 收起键。
- **算过**：收起后写作面占满宽度，刷新页面后仍是收起状态。

## ⑥ 侧栏下方功能按钮太小

- **改了什么**：目录页脚五键改为 **46×40**（原 27px 级），图标 1.25×；「导入小说」按钮 247×40、40px 高。
- **算过**：手指/鼠标都能一次点中。

## ⑦ 工具栏太挤 → 功能搬进设置

- **改了什么**：工具栏只剩 5 件：`☰` 目录 · 书名 › 章名 · `⛶` 沉浸 · `▤` 宿主侧栏 · `🔒` 锁定 · `⚙` 设置。备份、版本历史、主题、打字机、导出选项全部搬进设置（六个分区：外观 / 写作 / 导出与文件 / 隐私与锁定 / 投稿 / 快捷键）。
- **算过**：工具栏一眼看得完，不换行、不溢出。

## ⑧ 校对 / 排版 / 投投放右下浮动坞

- **改了什么**：`.nw-dock`（`right:20px; bottom:56px`）默认半透明 `opacity .35`，hover / 键盘聚焦变实；点 `✎` 展开三枚胶囊：`✍ AI 校对`、`¶ 一键排版`、`✉ 投稿`。
- **算过**：坞不压正文（写作面自动让出右侧 ≥88px）；展开 / 收起有弹性动画。
- 参见 `docs/screenshots/final-02-dock.png`。

## ⑨ 导入不放侧栏、导出收进「⋯」

- 说明：导入入口在**目录底部**（不在工具栏），导出在**每本书 / 每章行的「⋯」菜单**里，可按「整本书 / 仅当前章」导出。
- **算过**：hover 任一行 → `⋯` → 出现 `导出 / 重命名 / 删除`；点导出弹出带格式（Word / PDF / EPUB / 纯文本）与范围选择的对话框。

## ⑩ 本地加密

- **改了什么**：保存目录镜像可开「加密保存到该目录」（`NWENC1` + AES-256-GCM，密钥由 Host `secrets/key.bin` 经 HKDF-SHA256 派生、不落盘）；另有「解密出明文副本」按需导出可读 `.md`。
- **在哪儿看**：`⚙ 设置` →「导出与文件」。
- **算过**：勾选加密后同步，目录里是 `.nwe` 二进制；点「解密出明文副本」得到可读 `.md`。

## ⑪ 五套主题（默认 Claude）

- **改了什么**：`claude`（默认，`#faf9f5` / `#141413` / `#d97757`）、`harness`（跟随宿主）、`eye`（护眼 `#cce8cf`）、`night`（黑夜 `#1a1a18`）、`ink`（水墨 `#f4f2ec`）；旧值 `light/dark/parchment` 会**自动迁移**到新主题。
- **在哪儿看**：`⚙ 设置` →「外观」→ 五个色块。
- **算过**：切换后**整个外壳**（不只是写作面）跟着变，正文配色与对比度正常。
- 参见 `docs/screenshots/final-01-canvas.png`、`final-07-night.png`。

## ⑫ 光标加粗加黑

- **改了什么**：自绘光标 `.nw-cursor`，`--nw-caret-width: 3px`、`--nw-caret-color` 每套主题各自定义（claude `#141413`、night `#e8e6dc`、eye `#1f2a20` 等），圆角 1px，带 1.06s 闪烁（打字时立刻变实）。
- **算过**：光标明显比系统默认粗，且在护眼 / 黑夜主题下依然看得清。

## ⑬ Claude 风格 + 字号

- **改了什么**：默认主题 Claude，默认字号 **20px**（编辑器实测 25px / 行高 50px，取决于设置里的字号滑块）、行距 2、页宽 760px；纸面 `#faf9f5`、墨色 `#141413`、强调橙 `#d97757`；圆角 / 阴影 / 间距按 Claude 设计语言重排。
- **算过**：正文不再偏小，纸面有留白与设计感。

## ⑭ 设置里加导出选项

- **改了什么**：「写作」分区新增**文末追加内容**（如署名 / 联系方式 / 「未完待续」，可开关）、**导出包含书名与作者**、**封面图片**入口、**校对默认模型**。
- **算过**：填一段追加文字后导出 docx / epub，文档末尾出现该段（txt 同样生效）。

## ⑮ 导出文末追加

- **改了什么**：`export.build` 增加 `appendText`；docx 追加为独立段落、epub 追加 `<p>`、txt 直接接在末尾。
- **算过**：见 ⑭ 的导出验证。

## ⑯ 投稿全链路

- **改了什么**：右下坞 `✉ 投稿` → 三步向导：`① 选期刊 → ② 选稿件 → ③ 预览邮件`。内置 **16 家文学期刊**（名称 + 体裁 + 字数区间 + 投稿要求 + 邮箱位），可「管理」里逐条覆盖；`⚙ 设置` →「投稿」填 SMTP（主机 / 端口 / TLS / 用户名 / 授权码 / 保存 / 测试连接）与默认笔名 / 联系方式 / 回信邮箱；预览页显示主题行、正文、附件名与「按期刊要求做的调整」，未配 SMTP 时「确认投稿」**原地拒绝并给出去配置的入口**；发送走 Host 侧纯 net/tls SMTP（AUTH PLAIN/LOGIN、STARTTLS、multipart + base64 附件），记录落 `DSH_HOME/novel-writer/submissions.json`（最近 50 条）。
- **⚠ 必须你自己核对**：内置 16 家的**邮箱与征稿要求是空位 / 通用值**，界面统一标「待核对」。本插件故意不联网抓取征稿启事（避免把过期信息当权威），请在「选期刊 → 管理」里按官方最新启事填一次。
- 参见 `docs/screenshots/final-04b-submit-journal.png`、`final-03b-settings-submit.png`。

## 你反馈的其它四处（都改了，顺带在这份清单里验）

| 反馈 | 现在怎么样 | 怎么验 |
| --- | --- | --- |
| 打字机模式无效 | 光标行居中生效（实测偏移 −25px）；用 `≤` 叠层镜像测行位置，滚动由 `.nw-scroll` 承担 | 打长文，光标行应一直停在视口中部 |
| AI 校对不能选模型 / 默认 405 | 设置→「写作」→「校对默认模型」有 **51 个模型**可选（默认跟随当前模型）；405 根因是旧构建产物里的 `POST` 被 `GET/HEAD` 分支拦掉，已修 | 坞里点 `✍ AI 校对`，下拉换一个模型再校对 |
| 阿里云登录 405 | 见 ①，已换成「扫码登录」+ WebDAV 简单模式两条明路 | 设置→备份→云端 tab |
| 改密码没有旧密码验证 | 已强制：先验当前密码，错了显示「密码错误」；验证通过才会用旧密钥解开全部正文再换钥重封 | 设置→「隐私与锁定」→ 修改密码，先故意填错旧密码 |
| 编辑器打字不流畅 | 输入路径改为「不重排整篇」：镜像测量 60ms 节流、保存 1200ms 防抖、打字时只重启动画名不强制回流；实测 median 16.6ms/帧 | 连续快速打字，光标与高亮应跟手 |
| 点击创作台要自动隐藏宿主左栏 | 进面板自动 `layout.toggleSidebar()` 收起（`sessionStorage` 一次性守卫）；工具栏 `▤` 随时切回 | 退出再进面板，宿主左栏应自动收起；点 `▤` 能还原 |
| 不能选小说保存目录 | 设置→「导出与文件」→「选择…」调宿主原生目录选择器（也可手输路径），一键同步镜像 | 选一个文件夹 →「保存」→「同步」，目录里出现 `<书名>.md` 与 `library.json` |
